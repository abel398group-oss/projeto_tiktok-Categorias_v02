# Checklist de validação de produto (creator — TikTok Shop)

Documento **manual**. Não está ligado ao scraper nem à API: serve para **traduzir números dos relatórios em decisão antes de comprar ou escalar**.

Como usar: para **cada** produto ou SKU candidato (vindo dos relatórios), percorrer as secções e marcar **Sim / Não / N/A** onde fizer sentido. Se algo cair nos **critérios de veto**, pára e descarta ou adia — não há “hack” técnico que substitua isto.

---

## 1. Margem estimada

| Pergunta prática | Resposta rápida |
|------------------|-----------------|
| Preço de venda público que vês no catálogo / feed | _____ |
| Custo estimado (fornecedor, dropship ou marketplace típico) | _____ |
| Taxas TikTok Shop (comissões + restantes que apliques à tua conta) — estimativa | _____ € ou % |
| Lucro líquido **mínimo** que aceitas por unidade vendida | _____ |
| Sobram margens após esse mínimo? | ☐ Sim ☐ Não |

**Nota:** se não souberes taxas ao centavo, usa uma margem conservadora (% fixo alto) só para não te enganares.

---

## 2. Logística

| Pergunta prática | Resposta rápida |
|------------------|-----------------|
| Prazo de entrega que o cliente vai perceber (dias úteis) | _____ |
| Peso/volume elevado (= frete/caros / complexo)? | ☐ Baixo ☐ Médio ☐ Alto |
| Categoria histórica de devoluções (tamanho mal, defeito visual, não combina foto)? | ☐ Risco baixo ☐ Risco alto |
| Consegues garantir SLA razoável se escalar volumes? | ☐ Sim ☐ Não ☐ Por confirmar |

---

## 3. Potencial de conteúdo

| Pergunta prática | Resposta rápida |
|------------------|-----------------|
| O produto **é visual** nos primeiros 2 segundos? | ☐ Sim ☐ Não |
| Dá vídeo **antes/depois**, transformação ou “resultado rápido”? | ☐ Sim ☐ Pouco ☐ Não |
| Resolve um problema **claro numa frase**? | ☐ Sim ☐ Não |
| Dá para criar **variações** sem cansar a audiência (ângulos, usos)? | ☐ Sim ☐ Não |

Se três ou mais destas ficarem negativas, o produto pode vender bem em catálogo alheio mas **ser difícil de te trabalhar criativamente**.

---

## 4. Concorrência

| Pergunta prática | Resposta rápida |
|------------------|-----------------|
| Já há **muitos** vídeos genéricos do mesmo produto? | ☐ Poucos ☐ Muitos |
| Vês **creators com audiência parecida com a tua** a converter? | ☐ Sim ☐ Não sei ☐ Poucos |
| Sensação subjectiva: mercado neste nicho | ☐ Ainda há espaço ☐ Muito saturado |

Isto não vem nos teus relatórios internos: complementa **com uma volta rápida no TikTok** (pesquisas, sons, hashtags do nicho).

---

## 5. Teste inicial (antes de escalar compra ou stock grande)

| Passo | Feito |
|-------|-------|
| Gravar pelo menos **3 vídeos** com ângulos ou ganchos diferentes | ☐ |
| Definir **1 objetivo mensurável** (ex.: clicar bio, clicar produto no vídeo, visitar loja) | ☐ |
| Esperar período suficiente para ler **CTR / vistas / conversão** relativos aos teus padrões | ☐ |
| Só aumentar ou encomenda em massa se **passares um mínimo** que próprio definiste | ☐ |

O analytics interno diz quem pode ser forte no **mercado agregado**; o **teu teste diz** se funciona para **ti**.

---

## 6. Critérios de veto (parar já)

Marcar ❌ para descartar ou **não escalar até rever**:

| Critério de veto |
|------------------|
| ❌ Margem baixa mesmo com preço conservador — não vale o risco |
| ❌ Envio ou fornecedor imprevisível — stress e review negativo |
| ❌ Não tens como explicar o benefício num vídeo curto — não force |
| ❌ Compliance / produto restrito ou sensível no teu mercado |

---

## Como usar isto junto aos relatórios (sem automatizar)

| Relatório do sistema | Para que usar **antes** ou **depois** do checklist |
|----------------------|------------------------------------------------------|
| **Top Products** | Gera lista de SKU com **volume alto** → candidatos onde o mercado já provou procura |
| **Opportunities** | Lista “espaço” (boa nota + faixa média-baixa vendas nas regras) → candidatos a **testar** |
| **Product Score** | Ordenação interna tipo “prioridade dentro do que já existe na base”; cruza sempre com margem aqui |
| **Escalar (Validados / Apostas)** | **Validados** = candidatos a escala se checklist passar; **Apostas** = tratamento como piloto obrigatório |
| **Mapa de categorias** | Ver **em que pasta estás** quando queres repetir género de produto ou evitar dispersão |
| **Product Decision** (se usares)** | Como **resumo automatizado/heurístico** — não sobrepões ao veto de margem **sem números** |

Fluxo recomendável em prática:

1. Escolhe 5–15 linhas máx.** entre Score / Escalar / Opportunities (consoante objetivo da semana).  
2. Para cada uma, corre **esta checklist** na mesma folha ou bloco de notas.  
3. Só ficam para teste inicial **os que sobrevivem a margem + veto**.  
4. Depois dos 3 vídeos, decidires escalar só com resultado teu**, não só com score.**

## Exemplo rápido (fictício)

**Cenário:** O **Escalar — Apostas** mostra um SKU de organizador doméstico com score forte e avaliações boas nos dados.

Checklist rápido:

| Secção | Conclusão |
|--------|-----------|
| Margem | Custo Alibaba + taxas estimadas vs preço TikTok → sobram 6 €/uni. Aceito mínimo 4 € → **segue**. |
| Logística | Leve; entrega 7–15 dias no fornecedor que imaginas usar → **segue**. |
| Conteúdo | Empilhar, antes/depois de gaveta → **bom para vídeo**. |
| Concorrência | Muitos vídeos, mas género “saturation” só em áudio igual — decidiste ângulo “rotina mamã ocupada”. |
| Teste | 3 vídeos: transformação rápida, ASMR organização, “erro que cometias antes”. Métricas: CTR loja melhor que teu médio em 48 h. |

**Veredito:** não compras stock no primeiro dia; só após dois vídeos com sinal positivo encomendas **pacote médio**.
